# Копия сайта bestkeys.tilda.ws/remont-moscow

Точная копия (1:1) лендинга Tilda «Ремонт квартир «под ключ»» — проект 12663697, страница 268684509 (alias `remont-moscow`).

Оригинальный сайт на момент создания копии уже возвращает 404, поэтому HTML и все ассеты сохранены локально.

## Структура

```
index.html      — готовая страница (все ссылки переписаны на локальные ассеты)
assets/
  css/          — стили Tilda (grid, forms, popup, quiz, slds, блоки страницы и т.д.)
  js/           — скрипты Tilda (jQuery, lazyload, popup, формы, слайдеры, маска телефона и т.д.)
  img/          — все изображения (полноразмерные оригиналы)
  fonts/        — шрифты Gilroy, VKSansDisplay, Playfair Display
source.html     — исходный HTML страницы (как был скачан, без правок)
screenshots/    — скриншоты для проверки (final-1440.png, live.png, mobile.png)
```

## Как открыть

Из корня этой папки:

```bash
python3 -m http.server 8899
# затем http://localhost:8899/index.html
```

(или просто откройте `index.html` двойным кликом — всё локальное, интернет не нужен)

## Что проверено

- Полностраничные скриншоты локальной копии и живого сайта совпадают по геометрии: 1440×10104 px, смещений нет (расхождения ~4% — только из-за того, что на живом сайте часть картинок осталась в 20px-плейсхолдерах lazy-load; локальная копия показывает полные изображения).
- Попап «Получите консультацию» (#popup:call) открывается, формы и маска телефона работают (флаги стран локализованы в `assets/img/flags7.png`).
- Мобильная версия (375px) рендерится без ошибок.
- Консоль браузера — без ошибок.

## Примечания

- Ссылки на политику/заявки ведут на оригинальный домен (`https://bestkeys.tilda.ws/...`), т.к. эти страницы не относятся к лендингу.
- Отправка форм на локальной копии не работает (Tilda Forms требует сервер); визуально всё идентично.

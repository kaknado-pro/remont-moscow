## Что сделано

- Точная копия (1:1) лендинга Tilda `bestkeys.tilda.ws/remont-moscow` (проект 12663697, страница 268684509). Оригинал на момент копирования уже удалён (404), поэтому HTML и все ассеты сохранены локально.
- **Логотип и подпись** «Разработка сайта и маркетинг» — в шапке и в подвале (вместо телефона). Клик по логотипу/подписи ведёт на https://voroninded1987-dot.github.io/exponent-digital/
- **Номер телефона компании убран полностью** (шапка + футер + нижняя полоса).
- **Формы работают**: попап «Получите консультацию» и квиз «Рассчитать стоимость» отправляют заявки на рабочий backend `https://remont-kaknado.ru/sendmail.php` (тот же, что у основного сайта), после отправки — страница «Спасибо» (`thankyou.html`).

## Структура

```
index.html      — готовая страница (локальные ассеты)
thankyou.html   — страница «Спасибо» после отправки формы
assets/
  css/ js/      — стили и скрипты Tilda (локализованы)
  img/          — изображения + agency-logo.png (логотип)
  fonts/        — шрифты Gilroy, VKSansDisplay, Playfair Display, Montserrat
  js/send.js    — обработчик отправки заявок
.nojekyll       — отключение Jekyll на GitHub Pages
```

## Проверено

- Полностраничные скриншоты локальной копии и живого сайта: геометрия 1440×10104 px, смещений нет.
- Формы (попап + квиз) проходят валидацию телефона, отправляют заявку и редиректят на `thankyou.html` — проверено на опубликованном сайте.
- Тестовая заявка успешно ушла в backend: `{"status":"success","message":"Заявка успешно отправлена"}`.
- Консоль браузера — без ошибок, битых изображений нет.
